# Precios de referencia — cuándo promocionar de verdad

Antes de postear una "baja de precio" en redes, chequear acá si el precio nuevo
está realmente por debajo del mejor precio real que vimos antes — no solo por
debajo del "precio anterior" tachado que muestra Mercado Libre (ese lo puede
inflar el vendedor para figurar con descuento y posicionar mejor, sin que el
precio real haya bajado).

**Regla:** si el precio nuevo NO está por debajo de la referencia, no se
promociona como "oferta" — como mucho se postea sin el framing de descuento,
o se saltea directamente. Si está por debajo, se promociona Y se actualiza
la referencia acá con el nuevo mejor precio.

No mezclar variantes distintas como si fueran el mismo producto (ej. un
DualSense de color/edición especial no es comparable al DualSense estándar
negro — tienen precio de lista distinto).
